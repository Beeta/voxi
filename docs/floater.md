# 录制悬浮窗

录制开始时出现、录制结束时消失的闹钟小圆窗，用来提醒「录音还没停」。代码在
`internal/app/floater.go`，静音检测在 `internal/audio/recorder.go`（`QuietFor`）。

## 外观

- **平时**：直径 48pt 的圆，中间是 ⏰ 闹钟 emoji，外圈一道 3.75pt 的彩色描边（颜色随时长变化，
  见下表），没有文字，也没有录制圆点。闹钟看起来像计时器或提醒，外人联想不到录音。窗口比圆大 6pt 一圈
  （透明），给弹跳留出空间。
- **暂停中**：闹钟变淡。
- **定时弹跳**：每录满 10 分钟（`floatBounceEvery`），收起状态的圆弹跳两下，约 0.9 秒，最大放大到
  1.12 倍。开始录制时不跳；展开成胶囊时不跳。系统开了「减弱动态效果」时不跳。
- **悬停范围**：收起时整个 60×60 的正方形窗口都算「移上去」，圆外的四个角也能触发展开。
- **收起延迟**：鼠标离开后等 0.3 秒（`floatShrinkDelay`）再收起，期间鼠标回来就不收。避免鼠标停在边缘时窗口反复伸缩。
- **鼠标移上去**：展开成 294×60 的胶囊，显示计时、暂停/继续、停止（停止即「停止并保存」，
  没有丢弃）。圆点停在屏幕右半边时向左展开，左半边时向右展开，闹钟始终留在鼠标下面，
  展开后的那次点击不会误按到停止。
- **拖动**：拖闹钟或计时文字移动位置，位置记在 `window-state.json` 的 `floater` 键下，
  下次录制还在原处。第一次出现在主屏幕右上角。

## 随时长变色（外圈描边）

| 已录时长 | 颜色 |
| --- | --- |
| 0–15 分钟 | 绿 `#34c759` |
| 15–30 分钟 | 由绿渐变到黄 `#ffcc00` |
| 30–45 分钟 | 由黄渐变到橙 `#ff9500` |
| 45–60 分钟 | 由橙渐变到红 `#ff3b30` |
| 60 分钟以上 | 红 |

每段 15 分钟（`floatTintStep`）。

时长按实际写进文件的音频算，暂停的时间不计。

## 静音提醒

录制中每段写入的音频都会算一次 RMS，低于 `quietLevel`（0.003，约 -50 dBFS）算安静。
连续安静 3 分钟（`quietRemind`）后：

1. 外圈描边每秒明暗交替一次，直到又有声音；
2. 发一条系统通知「已经 N 分钟没有声音了，还需要继续吗？」，每段安静只发一次。通知文字
   不提「录音」。

暂停或继续会让安静计时重新开始。通知需要打包后的 `.app`，首次会弹出系统授权。

## 不被别人看到

- 悬浮窗设了 `SetContentProtection(true)`：屏幕共享、录屏和截图里都看不到它。
- 它是 mygo 的 `Panel` 窗口：浮在所有 App 和全屏 App 之上、每个桌面空间都有，不进 Dock 和
  Cmd+Tab，点它不会把主窗口拉到前台。
- 限制：使用麦克风时 macOS 菜单栏的橙色指示点和控制中心里的「正在使用麦克风」由系统显示，
  应用无法隐藏。

## 资源占用

- 不录制时悬浮窗不存在。
- 自己的循环每秒醒一次，只在显示内容变化时重绘：收起时每分钟一次（颜色步进），每 10 分钟一次不到 1 秒的弹跳动画，展开时每秒
  一次（计时），安静闪动时每秒一次。界面由 mygo 原生绘制，不起 WebView。
- RMS 是在已有的编码 goroutine 里对每块样本做一次平方和，相对 AAC 编码可以忽略。
